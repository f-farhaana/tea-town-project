# SEO launch & backlink checklist

Already in the build: unique titles/descriptions, canonical URLs, one H1 per page, prerendered HTML for every route, OG/Twitter
cards, `sitemap.xml`, `robots.txt`, real 404, JSON-LD (Organization, WebSite, 2 × Restaurant with address + hours, Menu with
MenuSection/MenuItem, BreadcrumbList). No ratings markup (none is verified).

## At launch
- [ ] Verify the domain in Google Search Console (`VITE_GSC_VERIFICATION`) and submit `/sitemap.xml`.
- [ ] Add GA4 (`VITE_GA4_ID`) if the owner wants analytics; update the footer privacy note accordingly.
- [ ] Set the website URL on both Google Business Profiles (use `/locations/al-jazzat` and `/locations/al-tarfa`).
- [ ] Set the menu link on both profiles to `/menu`.

## Legitimate backlink sources (none acquired yet)
- [ ] Both Google Business Profiles (website + menu links)
- [ ] Instagram bio (@teatownuae) → teatown.ae
- [ ] Linktree → add teatown.ae and /menu
- [ ] Verified delivery platform profiles (Talabat, Careem, Deliveroo, Noon Food) where listed
- [ ] Established UAE directories (e.g. Yellow Pages UAE, Connect.ae) — claim, don't create fake listings
- [ ] Sharjah restaurant/food guides, food bloggers and Instagram reviewers (genuine coverage only)
- [ ] Local publications, community groups, partner/supplier websites
Do not buy links or use link farms.
